# Changelog

## 0.3.0 — 2026-09-25

- Renamed the library and Web Component to Veyl (`veyl-signal`).
- Added six original field-system forms: Reactor, Gyre, Prism, Echo, Helix, and Rift.
- Added field/filament collection filters, live configuration controls, and agent-prompt copying.
- Kept explicit form geometry stable while the semantic activity state changes.
- Expanded Motion to 3× and set Echo as the gallery's featured form.
- Added a repository README, integration example, and contributor guide.
- Published the `veyl.dev` npm package with TypeScript declarations and a client-side ESM entry.

Earlier exploratory builds were not versioned releases.
