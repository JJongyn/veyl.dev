# Security policy

Veyl is a browser-side visual component and does not process credentials or send application data to a service.

If you find a security issue, please do not post exploit details in a public issue. Contact the maintainer privately through the contact options on [GitHub](https://github.com/JJongyn). Include the affected version, browser, impact, and a minimal reproduction. You will receive a response as soon as practical.

This project does not currently publish a supported release or security-fix timeline.
